Technical field guide Updated through 2026.1.0529.7

SpatialAnalyzer / point-cloud workflows

Cloud & colourization

The biggest improvements since 2023, what they change in practice, and where to find them.

The short version

SA moved from conventional scan clouds with improving filters and meshes to an Enhanced Cloud system built for large data, then added complete deviation-colour, RGB, intensity, cross-section and automation workflows around it.

The best changes

Ten upgrades that matter most

    Enhanced Cloud format

    An octree plus local surface normals makes large clouds faster to access, draw, light and search for features. Introduced as an opt-in in 2025.2.

Enhanced Cloud

Why the octree matters

An octree divides 3D space into progressively smaller boxes. SA can load, draw or search only the branches relevant to the current view or operation instead of repeatedly walking every point. Local normals add an estimated surface direction at each neighbourhood, improving lighting, proximity searches and feature extraction.

Reference quality

Why CAD is converted to a mesh

A tessellated reference is efficient for repeated closest-surface calculations. Chordal Distance limits how far the mesh may depart from the CAD curve or surface; Max Angle limits the change in direction between facets. Tighter settings increase fidelity and triangle count.

Result choice

Why you can colour either object

Colouring the measured cloud preserves the scan as the inspection result and is ideal for finding local defects. Colouring the mesh gives a cleaner, continuous presentation on the nominal shape. Cloud-to-cloud comparisons return a colourized Enhanced Cloud.

Colour controls

What the colour bar is doing

The palette is a legend for stored values, not decoration. Changing its range or band limits changes how deviations are classified visually; it does not change the measured geometry. Set limits to the drawing tolerance before judging a map.

03

Do not mix these up

Three kinds of “colour”

Deviation / false colour

A computed inspection value is mapped to a palette. Blue might mean below nominal, green near nominal and red above—according to the active scale.

Computed

RGB

The point’s captured or imported red, green and blue values represent real surface appearance. This is what PLY RGB import and RGB-zone filtering use.

Captured

Intensity

A scanner return-strength value, usually displayed as a grayscale or palette. RTC360 sends an intensity Enhanced Cloud; voxel callouts can report the stored intensity.

05

Release progression

How the capability evolved

2023.1

Better display, extraction and mesh feedback

Per-cloud point size, local circle/hole extraction, deviation histograms, probing-vector display and improved real-time mesh integrity, smoothing and incidence-angle colouring.

2023.2

Filtering gets faster and more reusable

Threaded segmentation accelerates feature-cloud filtering; direct cloud association, saved filter settings and slot extraction improve repeat work. Mesh display yields to point display when point selection is needed.

2024.1

Large live data and meshing mature

Faster visualization while several instruments stream high-rate data, a new General Mesh engine with presets and JSON configuration, Center in View and duplicate prevention during cloud feature searches.

2024.2

Cloud data becomes replayable

RSC export/import replays scan stripes with timing, instrument association and original base transform. Cloud-to-Swatch automation and richer ASCII cloud export arrive.

2025.1

Cross-sections become a full workflow

Create a cross-section from multiple clouds, measure ATS600 data directly into it, preserve filtered sphere-fit clouds, and choose measured geometry or raw cloud in batch feature measurement.

2025.2

Enhanced Cloud is introduced

Octree storage and local normals form the new foundation. Split Cloud, stronger rejection and ring-band filtering, automatic cloud-to-feature extraction and nearest-cloud reassociation reduce manual cleanup.

2026.1

Colourization becomes end-to-end

CAD-accurate reference meshes, cloud-to-CAD/mesh/cloud colour maps, RGB PLY data, direct mapping controls, RGB-zone filters, deviation/intensity callouts and expanded MP/SDK support complete the workflow.

06

Practical cautions

What to watch for

Enhanced Cloud is opt-in.

Existing jobs may still use the legacy cloud type. Enable it under Clouds & Mesh before expecting the new RGB, cross-section and colourized-result behaviour.

Voxel display is not the fit itself.

Voxelization is a display/acceleration representation. SA blocks Clouds-to-Objects fitting while a cloud is in voxel display mode to avoid an inappropriate fit.

Colour scale determines readability.

A dramatic map can simply be a narrow scale. Use drawing tolerances and confirm whether the map is signed deviation, absolute distance, RGB or intensity.

Install the current 2026.1 hotfix.

Build 2026.1.0529.7 fixes colourized cloud/mesh callouts and reports that were incorrectly forced to inches; values now follow the active units.

Nexus reporting was removed.

The 2024.1 Nexus Metrology Reporting cloud service is unrelated to point-cloud storage and was phased out in 2026.1. Do not plan a new reporting workflow around it.

RTC360 firmware needs validation.

The 2026.1 notes warn that firmware 7.02.2980 is incompatible with the documented wireless interface. Confirm the current supported pairing before changing scanner firmware.
