TURDGOBBLER'S DECK NAME COLOURIFIER - VERSION 6.7.4

QUICK START
1. Extract every file from the ZIP into one folder.
2. Open index.html in a modern browser.
3. Type a deck name, choose colours, then click or tap the finished name to copy it.
4. Paste the result into Magic: The Gathering Arena.

No installation, account, or internet connection is required. Everything runs locally in your browser and nothing is uploaded.

MAIN FEATURES
- One to seven directly positioned gradient colours.
- Full colour wheel and direct three- or six-digit hex entry.
- Mobile-friendly tube controls with collision spacing and drag-to-delete.
- Built-in palettes and ten persistent, custom-named local palette slots.
- Ordered W/U/B/R/G shortcuts for mono, guild, three-colour, four-colour, and five-colour identities.
- V6 name field by default, with an optional compact ALT VIEW.
- A fully opaque black finished-name/copy background matching Arena in both views and every interaction state.
- Italic, underline, and strikethrough formatting.
- Live Arena 64-character budgeting and unsupported-character feedback.
- Repeated spaces are preserved in the generated deck name.
- Keyboard support: Ctrl/Command+Enter copies and Ctrl/Command+Z undoes gradient changes.
- Reduced-motion support and supported-device haptic feedback.

LOCAL DATA
Gradient settings, formatting, mana selections, and saved palettes use browser local storage. Deck names are not stored. Clearing browser site data removes those saved settings.

ARENA NOTE
Arena currently ignores the bold tag, so Bold is intentionally hidden. The implementation remains easy to restore if Arena supports it again.

FILES
- index.html: open this file to use the tool.
- app.js: interface and interaction logic.
- logic.js: Arena encoding, gradient sampling, and collision logic.
- styles.css: complete interface styling.
- favicon and manifest files: optional browser icons and install metadata.
